SnapMon プライバシーポリシー

制定日: 2026 年 9 月 21 日

【開発者名】（以下「運営者」）は、スマートフォンアプリ「SnapMon」（以下「本アプリ」）における利用者の情報の取り扱いについて、個人情報の保護に関する法律（以下「個人情報保護法」）その他の法令を遵守し、次のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

本アプリは、次の情報を取得します。

1.1 アカウント情報

  • Google アカウントまたは Apple ID でサインインした際に、認証サービス（Firebase Authentication）から受け取る利用者 ID、表示名、メールアドレス
  • 利用者が申告する生まれた年（年齢確認のため）

1.2 写真

  • 利用者が本アプリのカメラ機能で撮影した、または端末の写真から選んだ「物」の写真
  • 写真に顔が写っているかどうかの判定は 端末内 で行い、顔が写っている写真はサーバーへ送信しません
  • サーバーへ送信した写真は、被写体の認識とモンスター画像の生成に使用したのち、「出自の写真」として利用者本人だけが閲覧できる形で保存します
  • 写真の撮影日時や位置情報（Exif）は、送信前に取り除きます。本アプリは位置情報を取得しません

1.3 歩数データ

  • 利用者が許可した場合に、端末の健康管理機能（Android: Health Connect、iOS: HealthKit / CMPedometer）から取得する歩数と、歩行・走行・乗り物などの活動種別
  • 取得する期間は前回の同期以降の分のみです。心拍数、睡眠、体重などの他の健康データは取得しません
  • 歩数データの取得はいつでも端末の設定から停止できます

1.4 ゲームデータ

  • モンスターの情報（名前、種族、属性、レベル、ステータス、生成された画像など）、活力ポイント、アイテム、トレーニングや対戦の履歴、チュートリアルの進捗
  • フレンド機能で利用者が入力したフレンドコード、フレンドの一覧、ブロックした相手
  • 通報機能で利用者が送信した通報の内容

1.5 端末と利用状況の情報

  • アプリの正当性を確認するための情報（Firebase App Check が生成するトークン。端末やアプリを識別する情報を含みます）
  • サーバーへのアクセス日時、エラーの記録
  • 将来、アプリの安定性向上のためにクラッシュ情報や利用統計を取得する場合は、本ポリシーを更新して告知します

1.6 購入情報

  • 有料サービスを提供する場合、決済は Google Play または App Store が処理します。運営者はクレジットカード番号などの決済情報を取得せず、購入した商品と購入の状態のみを受け取ります

2. 利用目的

取得した情報は、次の目的で利用します。

情報利用目的
アカウント情報利用者の識別、サインイン、年齢確認、問い合わせへの対応、規約違反への対応
写真被写体の認識（種族・属性の決定）、モンスター画像の生成、写真の使い回しの検出、出自の写真の表示
歩数データ活力ポイントの付与、モンスターの育成、不正な歩数の検出
ゲームデータゲームの提供、フレンドとの対戦、家系図などの記録、ゲームバランスの調整（統計としての利用）
端末と利用状況の情報不正なアクセスや改造されたアプリの検出、障害の調査
購入情報有料サービスの提供、購入状態の確認

歩数データは、上記の目的以外には使用しません。広告やマーケティングのために使用したり、第三者に販売したりすることはありません。

3. 外部サービスへの提供（委託）

本アプリは、次の外部サービスを利用しており、必要な範囲で情報を送信します。いずれも運営者が業務を委託する相手であり、各社は自社のプライバシーポリシーに従って情報を取り扱います。

提供先送信する情報目的所在国
Google LLC（Firebase: Authentication, Cloud Firestore, Cloud Storage, Cloud Functions, App Check）アカウント情報、写真、歩数データ、ゲームデータ、端末情報本アプリのサーバー基盤（保存、認証、処理）米国ほか
Google LLC（Cloud Vision API）写真被写体と色の認識米国ほか
OpenAI, L.L.C.（Images API）写真、被写体の種類と性格に応じた文章モンスター画像の生成米国

外国にある第三者への提供について

上記の提供先は日本国外（主に米国）に所在します。個人情報保護法に基づき、次の事項をお知らせします。

  • 米国の個人情報保護制度: 米国には連邦レベルで包括的な個人情報保護法はなく、分野別の法律と州法により保護されています。個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」も参照してください
  • 提供先が講じる措置: Google および OpenAI は、いずれも OECD プライバシーガイドラインの 8 原則に対応する措置を講じており、それぞれの利用規約およびデータ処理に関する規約に基づいて、運営者の指示の範囲でのみ情報を処理します
  • AI の学習への利用: OpenAI の API に送信した写真と生成された画像は、OpenAI の API データ利用方針（2026 年 9 月時点）により、OpenAI のモデルの学習には使用されません。Google Cloud Vision API に送信した写真も、Google のモデルの学習には使用されません

4. 第三者提供

運営者は、次の場合を除き、利用者の同意なく個人情報を第三者に提供しません。

  1. 法令に基づく場合
  2. 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合
  3. 前項の委託先への提供

他の利用者に見える情報

フレンド機能を使うと、フレンドになった相手には、利用者の表示名と、対戦に出したモンスターの名前・見た目・種族・属性・レベル・ステータス・技が表示されます。出自の写真、歩数、生まれた年、メールアドレスは他の利用者には表示されません。

5. 保存期間と削除

  1. 取得した情報は、アカウントが存在する間、保存します。
  2. 利用者が本アプリ内で「アカウントを削除」を行うと、アカウント情報、モンスター、出自の写真、歩数の記録、アイテム、フレンドの一覧をサーバーから削除します。削除後の復元はできません。
  3. 他の利用者との対戦の記録は、他の利用者のデータの一部でもあるため、利用者を特定できない形にして残ることがあります。
  4. 通報の内容は、通報への対応と再発防止のため、アカウント削除後も必要な期間保存することがあります。
  5. サーバーのバックアップに含まれる情報は、バックアップの保存期間（最長 30 日）の経過後に消去されます。

6. 安全管理措置

運営者は、取得した情報の漏えい、滅失、毀損を防ぐため、次の措置を講じます。

  • サーバーとの通信は暗号化します
  • 出自の写真は利用者本人だけが閲覧できるようアクセス制御を行います
  • モンスターの隠しパラメータやサーバーの処理は、利用者や第三者が直接読み書きできないようにします
  • 外部サービスの認証情報は、暗号化された専用の保管領域に保存し、プログラムやリポジトリに記載しません
  • 改造されたアプリからのアクセスを検出し、拒否します

7. 利用者の権利

利用者は、運営者が保有する自身の個人情報について、開示、訂正、追加、削除、利用の停止を求めることができます。第 10 条の連絡先までご連絡ください。本人確認のうえ、法令に定める期間内に対応します。

アカウントの削除は、本アプリ内の操作で利用者自身が行えます。

8. 子どもの利用

本アプリは 13 歳未満の方の利用を想定しておらず、13 歳未満と申告された場合は利用登録を行いません。13 歳未満の方の情報を誤って取得したことが判明した場合は、速やかに削除します。18 歳未満の方は、保護者の同意を得たうえで利用してください。

9. 本ポリシーの変更

運営者は、法令の改正やサービスの変更に応じて本ポリシーを変更することがあります。変更した場合は、本アプリ内および運営者のウェブサイトに掲載し、重要な変更については本アプリ内で告知します。広告や利用統計の取得など、新たに情報の取得を始める場合は、開始前に本ポリシーを更新します。
