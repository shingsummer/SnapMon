# 参考: ポケモンの戦闘・成長システムと SnapMon の比較

2026-09-21 調査。P6 バランス調整で「特殊防御の追加」「ステータス・技・命中率の見直し」を判断するための資料。
出典は Bulbapedia（Stat / Damage / Accuracy / Critical hit / Power / Priority / Effort values / Experience / Move / Nature）と PokémonDB の種族値表。世代によって細部が違う項目は **第 6 世代以降** の値で書く。

## 0. 要点

1. ポケモンは 6 ステータス（HP・攻撃・防御・特攻・特防・素早さ）。**特防は独立した値**で、特殊技は「特攻 ÷ 相手の特防」で計算する。SnapMon の「特攻が特防を兼ねる」形はポケモンには無い。
2. ポケモンの個体の強さ = **種族値（種の設計値）＋個体値（生まれつき、0〜31）＋努力値（育成、上限あり）＋性格（±10%）**。SnapMon はこれを「初期値（5〜60）＋素質（1〜10）＋トレーニング＋性格補正」で写している。対応関係は良い。
3. ただし **種族値の考え方（種ごとにステータスの傾向がある）は SnapMon に無い**。今の初期値は 6 ステータスとも一様乱数で、メタル族もフード族も統計的に同じ体型になる。これがポケモンとの一番大きな差。
4. ダメージ式は「攻撃 ÷ 防御」を直接使う。ポケモンでそれが成立するのは、種族値が 1〜255、個体値・努力値も上限つきで、**攻防の比が極端にならない**から。SnapMon の初期値 5〜60（比が最大 12 倍）でそのまま使うと Lv1 で一撃になる。比率形にした判断は妥当。
5. 命中率は大半が 100%。威力の高い技が 70〜90% を持ち、「威力と引き換えに外れる」のがルール。SnapMon の技表（150〜250 の威力、命中 0.8〜0.9 が 7 技）は同じ設計思想で、そのままでよい。
6. ランク補正は ±6 段階、+1 = 1.5 倍、−1 = 0.67 倍。SnapMon は ±2 段階、+1 = 1.3 倍。ポケモンは 1 戦が長い（数十ターン）ので積み技が報われる。SnapMon は 1 対戦 10 ターン上限・平均 4〜5 ターンなので、弱めの倍率で正しい。
7. 会心は基本 1/24（4.2%）で 1.5 倍。運のようなステータスは無く、技と持ち物で段階が上がる。SnapMon は運 ÷ 3000 で 2%〜33%、2 倍。会心を「運の見せ場」にするなら今のままでよいが、2 倍は大きめ。
8. 技は 4 枠、5 つ目を覚えるときに 1 つ忘れる。威力は 40〜120（平均 79）、高威力の技は命中低下・反動・反動ターン・自分の能力低下で釣り合いを取る。SnapMon の技効果の種類はほぼ同じ。

## 1. ステータス

### ポケモン

| 項目 | 内容 |
|---|---|
| 6 種 | HP、攻撃、防御、特攻、特防、素早さ |
| 種族値 | 種ごとの設計値。各 1〜255。合計は 195（キャタピー）〜680（ミュウツー）、メガ進化で 780。最終進化の一般的な種は 450〜550 |
| 個体値 | 各ステータス 0〜31。生まれつきで変わらない |
| 努力値 | 戦闘で得る。1 ステータス 252 まで、**合計 510 まで**。Lv100 で 4 努力値 = 実数値 +1 |
| 性格 | 25 種。1 つを +10%、1 つを −10%（HP は対象外）。5 種は無補正 |

実数値の式（第 3 世代以降）:

```
HP      = floor((2×種族値 + 個体値 + floor(努力値/4)) × Lv/100) + Lv + 10
その他  = floor((floor((2×種族値 + 個体値 + floor(努力値/4)) × Lv/100) + 5) × 性格)
```

Lv50、種族値 100、個体値 31、努力値 252 のとき: HP 207、その他 152（性格補正なし）。**HP だけ「+Lv+10」が乗るので、同じ種族値でも HP は他より 3 割ほど大きい**。ポケモンも HP を特別扱いしている。

種族値の例（HP/攻/防/特攻/特防/速 | 合計）:

| ポケモン | 種族値 | 特徴 |
|---|---|---|
| キャタピー | 45/30/35/20/20/45 \| 195 | 最弱級 |
| コイキング | 20/10/55/15/20/80 \| 200 | 弱いが進化で化ける（SnapMon の超晩成に近い体験） |
| ピカチュウ | 35/55/40/50/50/90 \| 320 | 速い、脆い |
| イーブイ | 55/55/50/45/65/55 \| 325 | 平均型 |
| ラッキー | 250/5/5/35/105/50 \| 450 | HP 特化・攻撃ほぼゼロ |
| ハピナス | 255/10/10/75/135/55 \| 540 | HP 上限 255 |
| ツボツボ | 20/10/230/10/230/5 \| 505 | 防御・特防特化、HP と速さが最低級 |
| フーディン | 55/50/45/135/95/120 \| 500 | 特攻・速さ特化 |
| リザードン | 78/84/78/109/85/100 \| 534 | バランス型 |
| カビゴン | 160/110/65/65/110/30 \| 540 | HP・攻撃型、遅い |
| ミュウツー | 106/110/90/154/90/130 \| 680 | 伝説 |

種族値の役割は「その種らしさ」。ラッキーは誰が育てても HP が高く攻撃が低い。**個体値・努力値は種族値の差を覆さない**（個体値 31 と 0 の差は Lv50 で実数値 15、努力値 252 で +32。種族値 100 と 50 の差は実数値 50）。

### SnapMon（現状）

| 項目 | 内容 |
|---|---|
| 6 種 | 体力、攻撃、防御、特攻、速さ、運（特防なし。特殊技は相手の特攻で受ける） |
| 初期値 | 各 5〜60 の一様乱数。ファミリー・属性による偏りなし |
| 素質 | 各 1〜10（隠し）。初期値と負の相関。上限 = 399 + 60×素質 |
| 成長タイプ | 早熟・平均・晩成・波型・超晩成（隠し）。ポケモンに相当物なし |
| トレーニング | 1 回 +2〜4 + 0.5×素質。1 日 8 回。上限は素質上限のみで **合計の上限なし** |
| 性格 | 8 種。レベルアップ補正 + 訓練の好き嫌い ±20% |

対応関係:

| ポケモン | SnapMon | 備考 |
|---|---|---|
| 種族値 | （相当物なし） | 初期値は一様乱数で、種の傾向を持たない |
| 個体値 | 素質 | 隠し値である点も同じ。SnapMon の方が影響が大きい（上限 459〜999） |
| 努力値 | トレーニング | ポケモンは合計上限で「どこに振るか」を迫る。SnapMon は時間さえかければ全部上限まで行ける |
| 性格 | 性格 | ほぼ同じ |
| レベル | レベル | 100 対 50 |
| 進化 | （なし。成長タイプで代替） | コイキング→ギャラドスの「化ける」体験を超晩成が担う |

### 示唆

- **特防を独立させるなら、ポケモンと同じ 6 種の並び（HP・攻・防・特攻・特防・速）＋運の 7 種**になる。運はポケモンに無い SnapMon 独自の値。
- **種族値の観点を入れるなら、ファミリーごとの「傾向」を初期値に持たせる**。例: メタル→防御・特防が高め、スパーク→速さ・特攻が高め、フード→体力が高め、ゴースト→特攻・速さが高め、ロック→防御・体力が高め、速さが低め。一様乱数 5〜60 の中心をファミリーごとに ±10〜15 ずらすだけで「その族らしさ」が出る。個体差（素質・成長タイプ）はそのまま残る。
- HP をポケモン同様に大きめに設計するなら、体力の初期値・上限だけ 1.3 倍にする手もある。今のシミュレータでは HP+100 の価値が最も高いので、上限を上げる代わりに **体力を上げる訓練を重くする**（現状も力仕事・耐久の副上昇でしか上がらない）という現状の形で釣り合っている。

## 2. ダメージ式

### ポケモン（第 5 世代以降）

```
ダメージ = ( floor( floor( (2×Lv/5 + 2) × 威力 × A/D ) / 50 ) + 2 )
           × 対象数 × 天候 × 会心(1.5) × 乱数(0.85〜1.00) × タイプ一致(1.5) × 相性 × やけど × その他
A/D: 物理技は 攻撃/相手の防御、特殊技は 特攻/相手の特防
```

- Lv50 同士、威力 80、A = D のとき: (22×80×1)/50 + 2 = 37。HP 実数値 150〜200 に対して **1 発 18〜25%**。SnapMon の狙い（Lv50 で 15〜20%）と同じ水準。
- 相性は 2 倍 / 0.5 倍 / 0 倍（無効）。複合タイプで 4 倍・0.25 倍まで。18 タイプ。
- タイプ一致（自分のタイプと同じ技）は 1.5 倍。SnapMon の「ファミリー技・属性技」は自分のプールから覚えるので、実質常にタイプ一致。
- 会心は攻撃側のマイナス段階・防御側のプラス段階を無視する。

### SnapMon（v1.3 §6.2、P6 で改訂）

```
ダメージ = 威力 × 攻/(攻+守) × 0.85 × (5+Lv)/55 × 段階補正 × 属性(1.5/1/0.67) × 会心(2.0) × 乱数(0.9〜1.1)
```

### 比較と示唆

- **攻 ÷ 守 を直接使えるかどうかは、攻防の値域で決まる**。ポケモンは Lv50 で攻撃 50〜200、防御 50〜200 程度に収まるので比が 0.25〜4 倍。SnapMon の Lv1 は 5〜60 で比が最大 12 倍。比率形 攻/(攻+守) は 0.08〜0.92 に収まるので、この差を吸収している。**もし初期値の幅を狭める（例: 20〜60）なら攻÷守に戻す選択肢もある**が、比率形のままで問題は出ていない。
- ポケモンの「+2」は低レベルでも最低ダメージを保証する項。SnapMon は `max(1, …)` で代替。
- 属性相性 1.5/0.67 はポケモンの 2/0.5 より控えめ。SnapMon は属性が 7 種で技のほとんどが属性付きなので、2 倍にすると相性だけで決まる。シミュレータでは 1.5 倍でも「弱点を突く側」の勝率 99.9%（全技が弱点属性の極端な条件）。現状維持でよい。
- 乱数幅: ポケモン 0.85〜1.00（期待値 0.925）、SnapMon 0.9〜1.1（期待値 1.0）。どちらでもよい。

## 3. 命中率と回避

### ポケモン

- 技の命中率は 30〜100 の 5 刻み。**大半の技は 100**。威力の高い技が命中を下げて釣り合う: ハイドロポンプ 110/80%、かみなり 110/70%、きあいだま 120/70%、ストーンエッジ 100/80%、ばくれつパンチ 100/50%。
- 必中技（スピードスター、つばめがえし など）は命中判定を飛ばす。
- 命中・回避の段階は ±6、倍率は 3/3 を基準に分子または分母を 1 ずつ増やす: +1 = 4/3（1.33 倍）、−1 = 3/4（0.75 倍）、+6 = 3 倍、−6 = 0.33 倍。
- 命中判定 = 技の命中率 × (命中段階 ÷ 回避段階)。

### SnapMon

- 100 技のうち命中 0.8〜0.9 が 7 技、残りは 1.0。回避を上げる技 4、命中を下げる技 3。段階倍率は攻防と同じ 0.3（+1 = 1.3 倍、−1 = 0.77 倍）で、ポケモンの 1.33 / 0.75 とほぼ同じ。
- 示唆: **現状のままでよい**。高威力技（240〜250）のうち命中 1.0 のものがあれば、命中 0.85〜0.9 に下げて釣り合いを取るのが「ポケモン流」。

## 4. ランク補正（バフ・デバフ）

| | ポケモン | SnapMon |
|---|---|---|
| 段階 | ±6 | ±2 |
| +1 / +2 / +3 | 1.5 / 2.0 / 2.5 倍 | 1.3 / 1.6 倍 |
| −1 / −2 | 0.67 / 0.5 倍 | 0.77 / 0.63 倍 |
| 1 戦の長さ | 数十ターン（3 対 3〜6 対 6、交代あり） | 1 対戦 最大 10 ターン、平均 4〜5 |

ポケモンで「つるぎのまい（攻撃 +2）」が強いのは、1 ターン使っても残り 10 ターン以上殴れるから。SnapMon は残りが 3〜4 ターンなので、+1 = 1.5 倍だとバフ持ちの勝率 78%、1.3 倍で 60%（シミュレータ）。**短い戦闘には小さい倍率**が正しい。今のままでよい。

## 5. 会心

| | ポケモン | SnapMon |
|---|---|---|
| 基本確率 | 1/24（4.2%）。段階 +1 で 1/8、+2 で 1/2、+3 で確定 | 運 ÷ 3000（Lv1 で 2%、Lv50 で 20〜33%） |
| 倍率 | 1.5 倍（第 5 世代のみ 2 倍） | 2.0 倍 |
| 上げ方 | 高会心技（+1）、ピントレンズ（+1）、きあいだめ（+2） | 運の成長、会心ボーナス付き技（+10〜15%）、運を上げる技 |

示唆: ポケモンは会心を「たまに起きる嬉しい事故」に留めている。SnapMon は運というステータスの存在意義が会心なので確率が高め。**倍率を 1.5 に下げて確率は今のまま**にすると、運の価値が下がりすぎる（運 +100 の勝率 56% → 53% 程度の見込み）。今の 2.0 倍・運 ÷ 3000 で「Lv50 で 4〜5 回に 1 回、2 倍」は遊びとして分かりやすいので維持でよい。ポケモン式にするなら「会心は防御側のプラス段階を無視する」を足すと、積み技への対抗手段になる。

## 6. 素早さと行動順

- ポケモン: 優先度（+5〜−7）→ 素早さ → 同速はランダム。でんこうせっか +1、まもる +4、トリックルーム −7。
- SnapMon: 優先度 0/+1 → 速さ → 同値はランダム。同じ構造。
- シミュレータで速さ +100 の勝率が 66% と高いのは、1 対戦が短く「先に殴った方が 1 撃多い」ため。ポケモンでも素早さは最重要ステータスの一つなので、これは自然。

## 7. 技

| | ポケモン | SnapMon |
|---|---|---|
| 枠 | 4。5 つ目は 1 つ忘れる | 4（＋師匠の型 1）。v1 は空き枠がある間だけ自動習得、入れ替えは v1.1 |
| 覚え方 | レベル、わざマシン、タマゴ技、教え技 | 誕生時 2、Lv10/20 で自動、師匠の型 |
| 威力 | 40〜120（平均 79）、多くは 5 刻み | 150〜250 |
| 分類 | 物理 / 特殊 / 変化（第 4 世代から技ごとに決まる） | 物理 / 特殊 / サポート |
| PP | 5〜40 回/戦 | なし（10 ターン上限が代わり） |
| 高威力の代償 | 命中低下、反動（1/4〜1/3）、反動ターン、自分の能力低下、PP 少 | 命中低下、反動 10%、なし、なし |

示唆:
- 威力の尺度は違うが、比率で見ると SnapMon の 150〜250（1.67 倍幅）はポケモンの 40〜120（3 倍幅）より狭い。**技ごとの差をもう少し付ける**余地がある（最弱 120〜最強 260 など）。ただし今の AI は期待ダメージ最大の技を選ぶので、弱い技は使われなくなる。弱い技には優先度・回復・追加効果を必ず付けること。
- 反動 10% は軽い。ポケモンのすてみタックル（威力 120、反動 1/3）に倣うなら、最高威力 250 の技は反動 25〜33% にしてよい。
- 4 枠の入れ替え（Lv30/40 で覚える技を選ぶ UI）はポケモンの根幹体験なので、v1.1 で入れる価値が高い。

## 8. 経験値とレベル

| | ポケモン | SnapMon |
|---|---|---|
| 上限 | Lv100 | Lv50 |
| 総経験値 | 60 万〜164 万（6 グループ） | 5,880 |
| 獲得 | 相手のレベルと種族の基礎経験値、自分とのレベル差で補正 | 訓練 15、勝利 20、歩行 100 歩 = 1、餌 30 |
| 成長の差 | 経験値グループ（レベルの上がりやすさ）だけ。**ステータスの伸び方は種族値で固定** | 成長タイプ（早熟〜超晩成）でステータスの伸びる時期が変わる |

SnapMon の成長タイプは、ポケモンの「進化でステータスが跳ねる」体験を、進化なしで再現するための仕組み。ポケモンに相当物はないので、そのまま独自性として残す。

## 9. 努力値の「合計上限」という考え方

ポケモンの努力値は合計 510（実数値 +63 相当）で頭打ちなので、「攻撃と素早さに全振り」「HP と防御に半々」のような **配分の選択**が生まれる。SnapMon のトレーニングは各ステータスの上限（素質）以外に制限がなく、1 日 8 回を続ければ全ステータスが上限に届く（上限まで 10〜27 回 × 6 ステータス ≈ 2〜3 週間）。

示唆: 「1 体につきトレーニング合計 N 回まで」を入れると、ポケモンの努力値と同じ「どこに振るか」が生まれる。ただし SnapMon は「歩いた分だけ強くなる」が核なので、上限で歩く意味を削ぐのは逆効果。**入れるなら β の実測（Lv50 到達日数と上限到達率）を見てから**。今は入れない。

## 10. 特殊防御を追加する場合の設計案

1. ステータスを 7 種に: 体力・攻撃・防御・特攻・**特防**・速さ・運（内部名 `sdf`）。
2. 特殊技のダメージは 特攻 ÷ (特攻 + 相手の特防)。特攻は攻撃専用になる。
3. 素質・初期値・上限・レベルアップ補正・性格補正を 7 つに拡張。ゴールデンテストは Python で再生成。
4. 訓練: 「受け身」（主 特防、副 体力、疲労 25）を追加。既存 4 訓練は変更なし。
5. 技: `spaStages` は特攻だけに効く。防御側の段階は `defStages`（防御）と新設 `sdfStages`（特防）。既存の技表で「特攻を下げて特殊技を受けにくくする」意図のものは特防に振り替える。
6. ファミリーの傾向（§1 の示唆）を同時に入れるなら、初期値の乱数中心をファミリーごとに ±10〜15 ずらす表を `shared-config/families.json` に置く。
7. アプリ: ステータス表示・グラフ・訓練画面を 7 対応。バトル画面は変更なし。
8. 既存モンスター: 本番はテスト個体のみなので、特防は「防御と同じ値・同じ素質」で補完して済ませる。
